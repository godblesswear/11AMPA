Adım adım web sitesi yapımı

Aşağıdaki sırayı izleyin. Tüm adımlar ücretsiz hesaplarla yapılabilir.

  1. Claude ile siteyi tasarlayın

    claude.ai'a girin ve sitenin konusunu, renklerini ve bölümlerini anlatın. Ne kadar net yazarsanız sonuç o kadar iyi olur. Örnek istek:

    Okul kulübüm için tek sayfalık, mobil uyumlu bir web sitesi yap.
Renkler lacivert ve beyaz olsun. Bölümler: Hakkımızda, Etkinlikler, İletişim.
Tek bir index.html dosyası olarak ver.

    Çıkan kodu kontrol edin, beğenmediğiniz yeri “başlığı büyüt”, “menüyü sadeleştir” gibi cümlelerle düzeltin. Sonunda kodu index.html adıyla bilgisayarınıza kaydedin.

  2. GitHub hesabı ve depo (repository) oluşturun

    github.com'da ücretsiz hesap açın. Sağ üstteki + simgesinden New repository'yi seçin, depoya gocpal-site gibi bir ad verin ve Public olarak oluşturun.

    Ardından uploading an existing file bağlantısıyla index.html dosyanızı yükleyin ve Commit changes düğmesine basın. Komut satırını tercih ederseniz:

    git init
git add .
git commit -m "İlk sürüm"
git branch -M main
git remote add origin https://github.com/KULLANICI_ADIN/gocpal-site.git
git push -u origin main

  3. Vercel'e GitHub ile giriş yapın

    vercel.com adresinde Continue with GitHub seçeneğiyle giriş yapın. Böylece Vercel, GitHub depolarınızı görebilir.

  4. Projeyi içe aktarıp yayına alın

    Vercel panelinde Add New → Project'e tıklayın, listeden gocpal-site deposunu bulup Import deyin. Ayarlara dokunmadan Deploy'a basın. Bir iki dakika içinde proje-adiniz.vercel.app adresinde siteniz yayında olur.

  5. Güncelleyin ve geliştirin

    Claude'dan yeni bir sürüm isteyin, GitHub'da index.html dosyasını açıp kalem simgesiyle yeni kodu yapıştırın ve kaydedin. Vercel değişikliği fark eder ve siteyi kendiliğinden yeniler. İsterseniz Vercel'deki Domains bölümünden kendi alan adınızı da bağlayabilirsiniz.

Sık sorulan sorular

Kod bilmem gerekir mi?

Hayır. Claude kodu yazar; sizin işiniz ne istediğinizi açıkça anlatmak ve sonucu kontrol etmektir. Zamanla kodu okumayı da öğrenirsiniz.

Bu yöntem ücretsiz mi?

GitHub ve Vercel'in bireysel kullanıma uygun ücretsiz planları vardır. Claude'un ücretsiz planında ise kullanım sınırları bulunur. Güncel koşullar için ilgili sitelere bakın.

Site adresim nasıl olacak?

Vercel size adiniz.vercel.app biçiminde ücretsiz bir adres verir. Daha sonra istersen kendi alan adınızı satın alıp bağlayabilirsiniz.

Yaptığım değişiklik sitede görünmüyor, ne yapmalıyım?

Vercel panelinde Deployments sekmesine bakın. Yayın tamamlandıysa tarayıcıda sayfayı Ctrl+F5 ile yenileyin.
